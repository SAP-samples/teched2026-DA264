# 2.0 Use Natural Language to Answer Queries about Calculation Views and Data

In this section we will load information about the created calculation views into a dedicated knowledge graph. While loading the knowledge graph we will also create data exploration tools in form of two procedures. You can use these procedures afterwards to ask in natural language questions about your calculation views and their content.

SAP HANA Cloud Central is the management interface for SAP HANA Cloud, which hosts also the Data Exploration Tools feature.

*To create these Data Exploration Tools open SAP HANA Cloud Central in another tab of your browser*
